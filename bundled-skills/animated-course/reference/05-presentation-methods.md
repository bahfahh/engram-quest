# 05 Ways of showing: what has been done (examples, not a menu)

The catalogue is organised by the layers of `03-adapter-pattern.md` §1: §3 stages and whole-middle methods (layer 1), §3b segment shapes (layer 2), §3c moment devices (layer 3), §3d links between segments and the ending. Most of §3 comes from **one course** — AdsDemo Meta Ads Playbook, a course for an indie app developer validating an app with NT$3,000 of Meta ads. It is an operate-a-tool subject, so real-interface methods dominate; later experiments added physics (Atlas), biology and abstract mechanisms (zoom out / zoom in). **For another subject, the learning principles and `03-adapter-pattern.md` §2 are a better start than this table**. If something here fits, use it; if it fits only loosely, design your own.

## 1. Status

| Status | Meaning |
|---|---|
| `approved` | The user reviewed it and found it good. Approved methods coexist; none replaces another |
| `trial` | Made, not yet reviewed by the user — evidence of an idea, not a rule |
| `rejected` | The user reviewed it and did not pick it. Write which content it was used for — the content can still be taught another way |
| `needs rework` | Direction approved, execution not |

Only the user's review changes a status: the user judges whether a finished film works.

**Free and Pro** (`11-teachers.md` §1b; the user's product decision): everything here is available to every teacher unless marked **Pro**; the Pro marks are the curiosity-and-depth devices that only Pro teachers (Nova, 包老師, Luna, Iris, Alden) use. Nico (free) keeps the full floor. Approved qualities for all teachers (how the aha is composed, only the change moves, the student's reaction, the recap that draws the path, carrying the object across a seam, recap-card words as an anchor, a wrong proposal answered by its right part first, quiet sound effects, closing a segment at its reveal) live in `04-skeleton.md` §2 and §6; the cue that travels a relation, two rulers and measured-and-true on one dial are in §3c, the bet on the blackboard in §3b, the map that asks the previous lesson in §3d.

**Approved means available, not required.** An approved method, shape or device is used where the segment's diagnosis calls for it (`03-adapter-pattern.md` §1) and left out where it does not fit; no lesson has to contain all of them, and none is a quota per segment.

**Experiment 20's approvals are methods, not a look.** Tests 1–28 were filmed on the Engram-studio base (`x19-a-light` → x20 … x33, lesson 6), so their example films (x22u, x27, x30r, x30u, x32n and the lesson-6 builds named below) show each method through studio parts: lights down, holo panels and the glass vault, the house colours (cyan, amber), station chips, the wipe. What the user approved is the method (timing, order, what moves, what is said); the lab notebook records it as 「通過的是做法（聲音、押注、提示、收圖……），不是明棚外觀；換回教室後照樣適用」 (`實驗20-高點閱研究AB實測/00-紀錄.md`, 2026-11-10). So the useful thing to take from those builds is their structure and timing, rebuilt in the lesson's own classroom and stage; their studio parts belong to a film the user asked to shoot in the studio (`01-principles.md` §1).

### Notes on the approved methods
- **Real interface**: easy to fall into the same shell every lesson; interface text in wide shots gets too small; the student shrinks to a jobless speech bubble. Components: `lib/kit/` (phone, feed, Ads Manager pieces, callouts, camera) — Meta-ads specific; build the equivalent for your subject's real screens.
- **Whiteboard**: came from a reference film the user liked (Google Cloud Tech, "AI Agent Memory Architecture"). Clean means few things, not small things — the one idea reads best filling the board. A split screen's other half earns its place by doing work (a case panel that changes with each idea, or a map of the decision flow lighting the current step); lesson 7's puppet sat idle. Implementation: one track per element (appear, vanish, move, draw line, stamp), `render(t)` a pure function of t (the render contract); DOM pages render cheaply (≈0.2–0.5 s per frame).
- **Atlas diagram world** (`lib/atlas/ATLAS.md`): plan the camera beats, the lit table and the explode moments in the understanding card before building. What worked: one colour per quantity for the whole film; tip-to-tail adding and cancelling as separate steps; drawn dimension lines to measure. It replaces only the middle: head and tail stay the classroom skeleton the user values. For single-concept lessons the course map can be a three-panel blackboard (already know → today → later), each panel held ≈ 3 s or more so it can be read.
- **Zoom out / zoom in decomposition** (experiment 18c). It fits a mechanism with no real picture; with a real screen, real code or a real organ, the real thing, focused, usually teaches better (`01-principles.md` §1 "Every frame has a focus"). Few-shot: the user's demo in the vault, (not public) — A card payment (2 frames + mindmap), B fees and compounding (2 + 1), C GPS (4 + 1), each with `00-說明與播放順序.html`; stills `assets/looks/6a–6d`, and the counter-example `6x`. References for a way of thinking, not templates; take what fits:
  - **Focus by size, position and contrast**: the subject is large and central; one accent colour means one thing (C: orange = the error only; B: orange = the gap only; A: purple = claim data going out, green = money coming back). Everything else stays in dark ink, clearly visible, rather than greyed to nothing.
  - **One sentence states the frame's point or question** (「手機的鐘一偏，測距就一起偏」「同樣 100 萬，30 年後差 142 萬」); a heading, a spoken question or a picture that says it alone can all work.
  - **The picture runs the mechanism with recognisable objects** (satellite → dashed line → phone with a stopwatch reading 0.07 秒; two circles crossing at two dots; store, bank buildings, coins), drawn large with solid fills — not 24 px outline icons.
  - **Real numbers and honesty labels stay** (0.07 秒, ≈ 21,000 公里, 574 / 432 / 142 萬; 「差距放大示意」), small and to the side.
  - **As many frames as concepts** (C four, A and B two), plus the whole at the end; one frame may build up over 20–40 s and stay on its one thing.
  - **Voice**: the picture shows, the voice gives the why. C03 example: *(both lines grow the same orange piece)* 「可是一微秒，光就跑了三百公尺——每一條距離，都一起被多算了三百公尺。」*(beat)*「所以鐘差不是小事，它就是第四個未知數。」— not 「左邊是手機，右邊是兩顆衛星」 (experiment 18: narration read the screen).
  - Producer brief and reviewer task used in 18c: the experiment's `製作工具/BRIEF-v3.md` and `REVIEW-v3.md` (vault, `研究/實驗18-整支片是地圖（六版測試）/`).
- **Review desk / report development / scale sandbox**: approved as middles, but their first versions had **no head and no tail**; they belong in the classroom skeleton, the default the user values.
