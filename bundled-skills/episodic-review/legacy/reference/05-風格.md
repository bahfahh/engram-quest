# 05 風格：四種外殼，或自己設計

> 「這次內容明顯比較好，但是外觀和氛圍反而沒第一輪好。」

## 1. 怎麼選

1. **先讀完內容**（`03-內容.md` 寫完 `CONTENT.md`），才選風格。不能先選風格再找內容來填。
2. 看這個月主題的**形狀**：
   - 分類、全景，想回到當時的地方 → 回到那個房間。
   - 結論有來由、前後修正、想看時間怎麼走 → 倒帶（鐵軌）。
   - 比較、互相牽連、有案子和證據 → 線索板。
   - 有清楚的邏輯結構，後來被修正或驗證過 → 思考城堡。
3. **都不合，就自己設計**：從「看的人會卡在哪」出發，用 `04-演示.md` 的原則，兩種檢驗驗收。新做的外殼標「試驗中」，等使用者審。
4. 一支片可以混用（例：外殼是房間，其中一間的演示用線索板的證物和紅線）。
5. 幾種都適合時，隨機選一種（使用者覺得比較有趣），回報時說理由。
6. **硬套是最糟的**：為了用某種外殼而扭曲內容，不如自己設計。

## 2. 認可過的外殼照用，不重新設計

第一輪就認可了「回到那個房間」和「倒帶回四月」的外觀，錯的是內容。第二輪的 9 月、10 月片卻把外殼換掉了（20 間房的剖面大樓配抽象裝置、黑底錄音帶）

所以：
- 用某種外殼時，**照下面描述的樣子和 `assets/looks/` 的參考圖做**，從 `assets/shells/` 的程式改，只換內容；演示先查 `assets/demos/README.md`，有現成的就換內容和參數，不重寫。
- 外殼的氛圍（光、季節、材質、真實物品）是「覺得很棒」的主要來源，不要為了放字把它改掉。
- 外殼是比喻，退到背景；主畫面給演示（`04-演示.md` 原則 4）。真實物品本身就可以是演示的地方（房間的螢幕、白板、桌上的紙）。

## 3. 四種外殼

### 3.1 回到那個房間（`rooms`）｜認可

參考圖：`assets/looks/rooms-*.jpg`；程式：`assets/shells/rooms/`（第三輪〈回到那個房間・九月〉的生產版，認可；附 README）。

**樣子**
- 一棟放在木頭轉台上的**剖面娃娃屋**，一層一個月（或一層一個領域）；亮燈的房間是要走進去的主題。片頭把房子轉一圈，要走的房間依序亮燈。
- 鏡頭穿過門框進去，**第一人稱**在房裡走。
- 房間是**真的房間**：窗外的光（清晨、午後、晚上、深夜）和季節，書桌、筆電、第二螢幕、日記本、便利貼、眼鏡、耳機。物件上的東西都來自筆記。
- 主動回想時，**房間燈熄掉**，只剩一件物件發光，下方安靜的倒數圓環。
- 觀點修正用同一個房間的「之後」：便利貼被劃掉、貼上新的；兩張並排。
- 片尾外殼吊起，房間一間間升空、換位置、落地，門牌掉光（拿掉情境再問一次）；最後歸位、全亮。

**這一版要改的**：一間房＝一個主題（不是一篇筆記、一天）；房裡的螢幕、白板、桌面就是演示的地方，把概念演出來（例：模型選型那間，桌上一台小機器只換訓練訊號演四次）。

**適合**：分類、全景；想讓人回到「當時在哪裡、做什麼」。配樂情緒：溫暖。

### 3.2 倒帶（`rewind`）｜認可，少用

參考圖：`assets/looks/rewind-*.jpg`；程式：`assets/shells/rewind/`（第三輪〈倒帶回十月〉的生產版，認可；附 README）。

**樣子**
- **山林裡的一條鐵軌**就是一段時間，低多邊形的樹，季節跟著時間變（秋天的落葉、夏夜、春天的花）。
- 開頭從高處看完全程：光帶沿軌道亮過去，月份門架標出時間，要停的站用光柱標出。
- 鏡頭降到軌道上移動：倒帶時落葉往上飛回、雨往上收、夜轉白天；到站後粒子恢復正常落下，代表時間重新開始。
- 站是**真實地點**和當時的桌面（咖啡店、圖書館），站裡的筆電、螢幕是內容。
- 主動回想：每站凍結，聲音抽掉，倒數。
- 快轉回來：光球沿鐵軌追上來，路燈依序點亮，把「這個想法後來長成什麼」變成看得見的移動。

**這一版要改的**：一站＝一個主題；站裡的螢幕、桌面演示內容。所以**少用**；用的時候，一站內的講解仍照正向時間（當初的問題 → 理由 → 現在的結論），鐵軌倒著走只當轉場和全貌。

**適合**：一段時間裡結論有來由、前後修正。配樂情緒：沉思。

### 3.3 線索板（`board`）｜認可

參考圖：`assets/looks/board-*.jpg`；程式：`assets/shells/board/`（第三輪〈八月的調查室〉的生產版，認可；附 README）。

**樣子**
- 暗房裡一面軟木牆，檯燈照著；一個主題是牆上的一個**案件區**。整理過，不混亂。
- 便條是重點；**證物照片、報告影本、程式碼影本、平面圖**是筆記的圖和實例（真的線索板本來就有照片和圖解）。
- 紅線上寫關係，連到圖上的某一處；案件之間的紅線寫「→ 案件幾」。
- 懸案（筆記裡還沒定的事）用黑底虛線便條。
- 片尾整面牆亮起，四條紅線連成一圈。

**這一版要改的**：第二輪的案件區幾乎只有字卡；要加證物和演示（例：mutation 報告照片、終端機影本、連線池的插槽被占滿）。

**適合**：比較、互相牽連；有案子、事故、證據。配樂情緒：好奇。

### 3.4 思考城堡（`castle`）｜試驗中參考《思考城堡》的打底 → 上梁 → 抗震。

**第一輪做錯了**：沿山脊蓋了一座真的城堡（地基石、梁、鐵閘、書庫）所以這裡沒有參考程式。

**怎麼做才對**：城堡指的是**思考的結構**，不是城堡的外觀。
- 打底：這個主題的問題、名詞定義、邊界，先擺穩。
- 上梁：因果、取捨、判斷規則，把結構撐起來；每根梁是一條「因為……所以……」。
- 抗震：後來的修正、反例、真實案子來搖它，看哪根梁撐住、哪根被補強（只用筆記寫的）。
- 外觀可以是任何能讓人看見結構長出來的方式（概念一塊塊疊起來的結構圖、骨架、模型），重點是看得出哪一塊撐住哪一塊。

**適合**：邏輯結構強、後來被修正或驗證過的主題。配樂情緒：沉思。第一次用時標「試驗中」，等使用者審。

## 4. 片子共用的部分（不管哪種外殼）

片頭 → 全貌 → 主題段 → 片尾快問 → 結尾，見 `06-片子規格.md`。全貌和外殼要讓人一直知道「現在在哪個主題」。
