# Pro upgrade artwork

The light and dark illustrations depict notes and learned concepts connecting to a visual explanation and video lesson. They were generated with the built-in ImageGen tool on 2026-11-13 and selected from the knowledge landscape concept. The original images and prompts are in the local design/pro-upgrade/2026-11-13-poster-concepts/ folder.

Runtime files are learning-notebook-light.webp and learning-notebook-dark.webp, 900 × 1200. The build embeds both through scripts/asset-list.mjs and the Pro dialog uses assetUrl. CSS selects the matching image using Obsidian's theme-dark class.
