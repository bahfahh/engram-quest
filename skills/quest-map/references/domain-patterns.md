# Domain Patterns

Use these patterns to select the right HTML mission shape. The source content decides; do not force a template.

## Software / systems

Good mission forms:
- bug hunt with highlighted code and repair choice
- incident triage with metrics and logs
- architecture routing decision
- state machine step-through
- latency/cost tradeoff dashboard

Learner actions:
- identify root cause
- choose mitigation order
- tune a threshold
- match symptom to layer
- sequence deployment or rollback steps

## Business / marketing

Good mission forms:
- A/B test decision from conversion data
- pricing or retention dashboard
- stakeholder tradeoff memo
- funnel diagnosis
- campaign budget allocation

Learner actions:
- calculate a metric first
- choose the safest next experiment
- identify confounding variables
- rank risks by business impact

## Medicine / health

Good mission forms:
- differential diagnosis
- triage from vitals and history
- treatment contraindication check
- anatomy or physiology mechanism map

Learner actions:
- eliminate diagnoses
- identify red flags
- pick next test
- explain why a tempting option is unsafe

Always avoid implying real medical advice. Frame as study simulation.

## Math / statistics

Good mission forms:
- scenario calculation before strategy selection
- graph interpretation
- probability simulation
- proof-step ordering
- error-spotting in a derivation

Learner actions:
- compute an intermediate value
- compare formulas
- select assumptions
- reason from a graph or table

## Science / engineering

Good mission forms:
- concept matching with mechanism explanations
- experiment design
- causal chain repair
- force/flow/energy diagram
- lab result interpretation

Learner actions:
- match components to functions
- predict outcome after parameter change
- diagnose failed experiment setup
- order causal steps

## Humanities / language

Good mission forms:
- evidence board
- timeline reconstruction
- rhetoric or grammar edit
- source comparison
- translation choice with nuance feedback

Learner actions:
- classify evidence
- choose the best interpretation
- identify implication
- revise text under constraints
