# 演示元件目錄：ep-oct〈倒帶回十月〉

這支片（認可）做過、檢驗過的演示。程式都在外殼 `assets/shells/rewind/` 裡（`demos.js` 是主角，`content.js` 管字和秒數）；**時間是原片的絕對秒數**（片長 609.9 秒），想看畫面就用該外殼算那一秒的定格。定格在 `stills/`，1920×1080。

使用原則：
- 元件綁在 `demos.js` 的 `buildS1R / buildS1L / buildS2 / buildS3` 裡，用 `update(t)` 切 `mode`（t 的純函數）。要重用，複製那一段子畫面和它的 `update` 片段，改字（`TXT` 的 id）、數字、秒數；不要整個站搬走。
- 字都從 `content.js` 的 `tx(id)` 讀。換內容先在 `TXT` 加 id，再在 demo 裡用 `T(parent, id, class, css)`。
- 演示的秒數對應一拍（`B1.five`…），拍的長度在 `content.js` 的 `beats([...])`。
- 時間範圍裡的「鏡頭」才看得見螢幕：同一拍裡鏡頭不在螢幕上的時段（例如軟木板特寫）演示在跑但看不到。
