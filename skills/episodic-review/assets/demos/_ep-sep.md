# 演示元件目錄：ep-sep〈回到那個房間・九月〉

來源：`../shells/rooms/`（生產檔，使用者看過成片、認可）。下面每一個都在程式碼裡確認過真的存在，定格是從 `shells/rooms` 的複本算出來的（1920×1080、`RENDER_GPU=1`，檔名 `stills/ep-sep-<名>.jpg`）。

**怎麼讀**
- **時間範圍＝成片秒**（`mm:ss`，片長 9:56.3）。想重看某個畫面：`RENDER_GPU=1 node render.cjs projects/<id> --stills <秒>`。「螢幕在跑」是這個子畫面存在的時段，「鏡頭看得到」是 `film.js` 的鏡頭關鍵格對著它的時段（其餘時段演示在跑但沒人看）。
- 程式裡的秒數是**故事秒**（`content.js` 的 `B`／`TEXT.t0`），算圖時由 `WARP` 換成成片秒；在 `shells/rooms` 裡用 `unwarp(故事秒)` 可以反查。
- 三台螢幕各自是一個 `drawMonN(ctx, w, h, t)`（1600×922），三面白板 `drawBoardN`（2560×1448）；全都是 t 的純函數、字從 `T['<id>']` 取（`content.js`）。
- **搬到新片**：複製那個函數（和它用的小函數），把用到的 `T[...]` id 在新片的 `content.js` 補上，把函數掛進 `drawMonN` 的切換條件（以 `B` 的拍點為界）。顏色 `C`、小工具 `text/wrap/box/arrow/pathArrow/code/check/cross/card` 都在 `draw.js`。
