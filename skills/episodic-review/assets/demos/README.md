# 演示元件目錄

本版的目錄裡，有些條目沒有定格圖；照文字描述使用即可。

做片時先在這裡找：**有現成的就換內容和參數，不要重寫**；短版（`reference/10-片長與成本.md`）只用這裡的現成元件。找法：從概念的定義句找動詞（`reference/04-演示.md`），對下面的「演什麼」。

每份目錄有每個元件的定格、程式在哪、怎麼改參數、成片裡的時間；定格在 `stills/`（1920×1080）。程式在對應的外殼資料夾（`../shells/`），所以要先把那個外殼複製進專案。

## 場景級的做法（不是螢幕演示，也值得重用）

- **回想**：房間暗下、只剩一束光照著問題卡、6 秒倒數，揭曉時翻面（aug §16）；燈熄的做法在 `rooms/`（sep 目錄的「場景級」節）。
- **收束**：軟木板上的紅線環、三張證物拉紅線 → 小心智圖 → 懸案釘進空位（aug §17、oct §12）。
- **全貌**：牆上的卡片翻面、工作燈依序照亮（aug §18）。
- **快問**：拿掉房間，一張索引卡填滿畫面，附演示縮圖當提示（aug §19）。
- **進門就在發生的問題**：先看到問題，再進來找原因（sep §14）。
- **時刻表**：要停的站一列列亮起，小縮圖先預演（oct §13）。

## 注意

- 演示裡的數字（例如 Rubric 的 15／19、19／29，連線池的 ≈205）常寫死在程式裡，重用要手改，而且要和你的內容對得上（`reference/03-內容.md` 第 6 節「事實要對」）。
- 這些演示是第三輪三個主題的**例子**，不是要每支片都塞滿；仍然是「看完內容再選要演什麼」。
- 站數、案件數、房間數寫死在外殼裡；見 `../shells/README.md` 的「注意」。
