# 外殼參考程式

這裡換成**第三輪的生產程式**（雲端算圖實際用的那一份，算得出圖）。第一輪、第二輪的舊外殼程式已被取代，git 歷史還在。

只拿**外殼**（空間、光、季節、材質、鏡頭、回想時燈熄的手法、片尾重排）和**演示元件**（見 `../demos/`），**內容全部要換**。

| 資料夾 | 來源（成片） | 外觀 | 適合 |
|---|---|---|---|
| `rooms/` | 〈回到那個房間・九月〉（`ep-sep`） | 剖面娃娃屋、飛進房間、桌上螢幕和白板、窗光隨季節和時段、回想燈熄、片尾房間升空換位 | 主題各自獨立、每個主題一個「房間」；有程式、資料流、圖表的演示 |
| `rewind/` | 〈倒帶回十月〉（`ep-oct`） | 低多邊形山林鐵軌、季節、只走一個月份、站裡是房間（大螢幕演示） | 一個月份內由淺入深的幾站；評分、比對、骨架這類「對照」的內容 |
| `board/` | 〈八月的調查室〉（`ep-aug`） | 掛在夏日午後房間裡的軟木線索板：案件卡、紅線、懸案便條、聚光 | 問題導向的案件；每個案件有真實的程式、報表、監控 |

每個資料夾有自己的 `README.md`：外觀、檔案地圖、**換內容的地方**（內容、字、鏡頭腳本在哪個檔）、怎麼試跑、已踩過的坑、不要改什麼。

## 怎麼用

1. 讀完內容後選外殼（`legacy/reference/05-風格.md`）；一支片可以混用，也可以都不選、自己設計。
2. 把外殼資料夾複製進 `$STUDIO/projects/<id>/`（`legacy/reference/07-製作與工具.md` 第 3 節），換內容；每個外殼的 `README.md` 寫了改哪裡。
3. 演示先看 `../demos/README.md`：有現成的就換內容和參數，不要重寫；短版（`legacy/reference/10-片長與成本.md`）只用現成的。
4. 先算一張定格看外觀有沒有跑掉，再往下做。

## 注意

- **還沒做成設定檔驅動**：站數、案件數、房間數寫死在各檔（例如 `rewind/` 是 3 站、`board/` 是 3 個案件），換數量不只是改一個設定。各 `README.md` 列出了位置。這是下一輪的整理項目（改完要重算定格比對，確認外觀沒變）。
- 數字（例如 Rubric 的 15／19、19／29）寫在演示的程式裡，重用要手改。
- 中文字：`rewind/assets/*.svg` 走系統字型，雲端算圖機沒有 CJK 字型時會缺字；先轉成 PNG 再用（`legacy/reference/07-製作與工具.md`）。
- **換影片語言**：改內容檔（`content.js`）開頭的 `LANG`；外殼固定的介面字（片頭提示、快問、卡片標題）在同一處的 `UI_SETS`，內建繁體中文和英文。主題的字一樣要換，還有一些留在演示程式裡的字，各 `README.md` 的「換內容的地方」列出了位置。語言規則見 `legacy/reference/06-片子規格.md` 第 2.5 節。
- 第一輪的思考城堡照字面蓋了城堡，被否定，沒有程式。
- 舊版聲音檔 `sound.py`（裡面的〈Morning〉和底噪）已刪除；配樂一律用 `scripts/music/`。
- 參考圖在 `../looks/`。
