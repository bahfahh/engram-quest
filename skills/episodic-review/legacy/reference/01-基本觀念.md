# 01 基本觀念

順序永遠是：**目的 → 給人看的東西 → 需要哪些資料 → 怎麼處理**。先想清楚目的和要給人看什麼，才動手收資料。

## 1. 目的

讓使用者把幾個月前學過、想過的東西拿回來用：想得起當時為什麼學、怎麼想、結論是什麼、後來有沒有修正。

- 筆記寫完很少再看。幾個月後只剩「好像學過」：有熟悉感，想不起內容。
- **所以回顧的時候，使用者自己就是陌生人**，寫筆記當時的脈絡已經想不起來了。
- 這要做進 engram 插件給任何人用，不管對方的筆記怎麼寫（很亂、寫日記、結構嚴謹都要能用）。

## 2. 驗收：陌生人看得懂，畫面也看得懂

**最終的片，就算不是這個使用者，看完也能明白：這個主題在講什麼、結論是什麼、為什麼。**

為什麼用這個標準：
1. **回顧時你就是陌生人。** 片子要靠你記得「8/22 那晚」「05_auth_rbac」才看得懂，就會在最需要它的時候失效。
2. **看得懂，才想得起來。** 回憶是重建，要有結構和道理才組得回來；日期和檔名只給熟悉感。
3. **逼出整理過的內容。** 拿掉時間、檔名、改動紀錄，剩下的就是問題、答案、理由、關聯、判斷規則。
4. **對任何人的筆記都成立**，不用替每種筆記另訂規則。
5. **情境才會真的是加上去的。** 主體內容自己站得住，情境只是給本人的一行入口。

驗收分兩半，**兩半都要過**：
- **字的檢驗**：把內容給沒看過這些筆記的人（或沒讀過的 AI），請對方用自己的話講回來。
- **畫面的檢驗**：遮掉字的定格給沒看過的人看，說得出每個畫面在演什麼機制。只做字的檢驗，字會越改越好，畫面卻只剩放字的地方（第二輪就是這樣）。

## 3. 不是教學片，但要講清楚

- 不是教學片：沒有老師、教室，不從零教，不加筆記以外的資料。內容只有筆記，照筆記自己的邏輯排，包含使用者自己的判斷。
- 但「不是教學片」**不排除讓人看懂的方法**。筆記本身就在解釋概念：寫了做法、例子、真實的案子、圖。片子要講到筆記的深度，所以看起來也有「解釋概念」的感覺，這是對的。

## 4. 內容從哪來：筆記現在的樣子

- **看筆記現在的樣子。** 現在的筆記是想完之後的結果，本身就有邏輯：一句話總結、大綱、表格、canvas 的群組和連線、地圖系列的順序、筆記之間的連結。回顧要呈現的就是這個邏輯。
- **中間怎麼改不看。** 哪天幾點存的、改了哪幾行、同一天改口，都不影響要給人看的東西。
- **一篇筆記是一個完整的想法**，整篇讀，不切成句子。
- **canvas 先畫成圖再看**：看群組、箭頭、連線上的字；只讀 JSON 容易看錯。canvas 本身就把關聯寫好了，不要拆掉重來。
- **觀點有沒有修正，看筆記裡自己寫的**（例：「當年不選外部登入的理由要重新評估」），不去比對改動紀錄。
- 整庫重整（大量搬移、改名）的日子當例外，不算學習。

## 5. 主題：單位，而且要完整

- **主題是同一件事的一組筆記。** 有整理的人，用自己的結構（資料夾、canvas、地圖系列）；沒整理的人，依內容分組，一樣以整篇為單位。
- **時間只決定「回顧哪些主題」，不決定「展示哪些內容」。** 這個月某個主題只動了一篇，也要把整個主題拿出來（合併其他天、其他月的筆記）。
- 全貌也要陌生人看得懂：每個主題一句話說它在回答什麼問題，再說主題之間怎麼接。

## 6. 時間線：只做兩件事

1. **選範圍**：這段期間動過哪些筆記，牽出哪些主題。
2. **情境標籤**：「8 月底」「做採購專案那陣子」，給本人當入口，一行就好。這一行一定是字。

時間不切內容、不決定內容的順序（順序照主題自己的邏輯），也不分析每天的改動。講一個主題時，**預設照正向時間**：當初的問題 → 理由 → 現在的結論。

## 7. 人類記憶：設計會用到的部分

| 觀念 | 意思 | 在片子裡 |
|---|---|---|
| 熟悉感不等於回憶 | 看到日期、檔名覺得「有寫過」，但講不出內容 | 不拿這些當內容，要放道理 |
| 編碼、儲存、提取 | 忘記多半是提取不出來、找不到入口 | 給入口（情境），讓使用者練習提取（回想） |
| 語意記憶與情節記憶 | 道理 vs 自己經歷過的事 | 主體是道理，情節只當入口 |
| 情境依賴記憶 | 提取時的線索越像學習當時，越容易想起 | 用當時的問題、專案當入口；外殼營造當時的氛圍 |
| 記憶＝情境＋情緒＋意義 | 找「筆」難，找「桌上那支筆」容易 | 入口要具體；氛圍和真實物品幫助回到當時 |
| 回憶是重建 | 用記憶積木加想像組出來，可能是錯的 | 給結構和道理；想像的畫面和筆記的事實分開 |
| 分塊、基模 | 有結構的東西好記 | 用主題原本的結構，不打散 |
| 具體性效應 | 具體例子比抽象說法好記 | 用一個真實的案子串起主題 |
| 雙重編碼 | 文字加圖，記憶多一條路 | 放筆記自己的圖，把概念演出來 |
| 精緻化 | 知道怎麼做、為什麼，新知識才接得上 | 講到做法，不只講名稱 |
| 提取練習 | 自己想出來比再看一次記得牢 | 每個主題先問後給 |
| 多情境提取 | 只在原本的情境想得起來是副作用 | 片尾拿掉外殼和情境再問一次 |

## 8. 四個感覺怎麼做到

| 感覺 | 怎麼做到 |
|---|---|
| 1. 重新思考、回憶 | 每個主題都先問後給：問道理，畫面真的停下來等 |
| 2. 結構清晰，一個主題一個單位 | 進去、看完、收起來，再進下一個；全貌一直在，知道現在在哪 |
| 3. 看完有思考、幫助記憶 | 結構綁在空間位置上；每個主題一行情境；片尾拿掉外殼再問一次 |
| 4. 覺得很棒 | 外觀和氛圍要好（真的空間、光、材質、季節、真實物品），一兩個「哇」的時刻，節奏有長有短，配樂安靜好聽。**第二輪內容比較好，但外觀和氛圍沒第一輪好**：兩者都要 |
